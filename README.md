# US Stock Return Prediction with Machine Learning

Machine Learning for Finance research project — predicting monthly cross-sectional
stock returns for the US equity market (1972–2025) and evaluating long-short
trading strategies built on those predictions.

**Author:** Zaixuan Quan (University of Bonn)
**Full report:** [Zaixuan_Quan.pdf](Zaixuan_Quan.pdf)

## Overview

The project trains and compares several machine learning models to predict
next-month stock returns from a panel of firm-level characteristics, then
tests whether those predictions translate into a profitable long-short
trading strategy.

- **Universe:** all US common equities in CRSP, January 1972 – December 2025
- **Models:**
  - Linear: OLS, Ridge, Lasso
  - Dimensionality reduction: PCA, PLS
  - Trees: Decision Tree, Random Forest, Bagging, Boosting (`HistGradientBoostingRegressor`)
  - Classifiers: Logistic Regression, Multinomial Logistic Regression
- **Training scheme:** pooled panel regression on a rolling 240-month window,
  predicting one month ahead
- **Backtest:** each month, sort stocks into 10 deciles by predicted return,
  go long the top decile / short the bottom decile, both equal- and
  cap-weighted; evaluate cumulative return, Sharpe ratio, volatility, and
  max drawdown
- **Universe filters:** results are compared across the full universe, a
  mild bottom-10%-by-market-cap trim, and the stricter HXZ (Hou, Xue &
  Zhang, 2020) NYSE 20th-percentile microcap exclusion

**Headline result:** Boosting is the most consistently profitable model.
Most of the strategy's excess return is concentrated in micro-cap stocks —
once those are filtered out, predictive power largely disappears. Strategy
performance also weakens noticeably after 2018, suggesting a structural
shift in the market rather than just a modeling issue. Full discussion,
tables, and figures are in the [report](Zaixuan_Quan.pdf).

## Data

Raw data is **not included in this repository** (CRSP is licensed data
distributed via WRDS, and the full panel files are too large for git).

Data sources used to build the panel:

- **CRSP Monthly Stock File** — stock identifiers, prices, returns, market
  cap, volume, shares outstanding
- **OSAP (Open Source Asset Pricing library)** — value, profitability,
  growth, momentum, risk, liquidity, and earnings-surprise factors
- **Goyal-Welch Predictor Data** — macro variables (T-bill rate, term
  spread, default spread, risk-free rate)

## Repository structure

```
.
├── Zaixuan_Quan.pdf              # Full write-up: data, methodology, results, discussion
├── scripts/
│   ├── data_preparation.ipynb            # Builds the panel dataset from CRSP + OSAP + Goyal-Welch
│   ├── model_backtest.ipynb              # Baseline: trains all models, runs the backtest (no filter)
│   ├── model_backtest_mild_filter.ipynb  # Same pipeline, bottom-10%-by-market-cap trim applied
│   ├── model_backtest_hxz_filter.ipynb   # Same pipeline, HXZ microcap exclusion applied
│   └── stocks_per_month_by_filter.py     # Plots stock counts under each universe definition
└── output/                       # Charts and metrics generated by the notebooks above
    ├── *.png / *.csv                     # Baseline (full universe) results
    ├── mild/                             # Results under the mild filter
    └── hxz/                              # Results under the HXZ filter
```

## Reproducing the results

1. Obtain the CRSP, OSAP, and Goyal-Welch data described above and place it
   alongside the scripts (paths are referenced relative to `scripts/`).
2. Run `scripts/data_preparation.ipynb` to build the feature panel.
3. Run any of the `model_backtest*.ipynb` notebooks to train the models and
   reproduce the corresponding figures/metrics in `output/`.

Requires Python 3 with `pandas`, `numpy`, `scikit-learn`, `matplotlib`, and
`shap`.

## Limitations

See Section 5 of the [report](Zaixuan_Quan.pdf) for a full discussion,
including forward-looking bias risk, transaction costs not being modeled,
and why dimensionality reduction underperformed expectations.
